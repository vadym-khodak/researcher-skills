# Write a Research Proposal

## Overview

Structures and drafts a research proposal that clearly states the problem, justifies the study, and demonstrates feasibility. Adapts to academic (thesis/PhD) or funding (grant) contexts.

## Workflow

1. **Identify context** — thesis proposal, PhD application, grant application, or coursework (ask if unclear)
2. **Identify funder/institution requirements** — word limit, required sections, formatting rules
3. **Gather inputs** — topic, research question, any preliminary ideas about methodology
4. **Draft section by section** — following the structure below
5. **Review coherence** — confirm that question → methodology → expected outcomes form a logical chain

## Standard Proposal Structure

```
1. Title
2. Background / Problem statement   — why this topic matters; what is known
3. Research gap                     — what is missing or contested in the literature
4. Research question / Aim          — the specific question this study will answer
5. Objectives                       — 3–5 concrete steps to achieve the aim
6. Methodology                      — design, sample, data collection, analysis plan
7. Expected outcomes / Contribution — what the study will produce and why it matters
8. Timeline                         — realistic milestone schedule
9. References                       — key sources cited in the proposal
10. Budget (grant applications only) — itemised costs with justification
```

## Section-by-Section Guidance

| Section | Key question to answer | Length (indicative) |
|---------|----------------------|-------------------|
| Background | Why does this problem need studying? | 200–400 words |
| Gap | What specifically is unknown or understudied? | 100–200 words |
| Research question | What exactly will this study find out? | 1–3 sentences |
| Methodology | How will the data be collected and analysed? | 300–500 words |
| Expected outcomes | What will the findings contribute? | 100–200 words |
| Timeline | Is this achievable in the given period? | Table or Gantt chart |

## Coherence Check

Before submitting, verify the logical chain:

```
Problem exists → Gap identified → Question addresses gap →
Methodology answers the question → Outcomes fill the gap → Contribution is clear
```

If any link is weak, the proposal reads as unfocused.

## Ukrainian-Specific Notes

| Context | Notes |
|---------|-------|
| Заявка на грант | НРФУ (National Research Foundation of Ukraine) and EU Horizon proposals have specific templates — ask for the template before drafting |
| Тема дипломної роботи | For Ukrainian theses, the proposal is often called «заявка на тему» or «технічне завдання» — check your ЗВО's form |
| Наукова новизна | Must be explicitly stated in Ukrainian academic proposals: what has not been done before and what this study will establish |
| Науковий керівник | Include the supervisor's name, degree, and academic title in the proposal — required by most Ukrainian institutions |

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| Vague problem statement | Cite specific evidence that the problem exists — statistics, policy gaps, practitioner needs |
| No clear gap | State explicitly what the literature has NOT yet answered |
| Methodology doesn't match the question | Check: can this method actually answer the stated question? |
| Unrealistic timeline | Add buffer between stages; data collection always takes longer than expected |
| Missing references in the proposal | A proposal with no citations looks like the author hasn't read the field |
