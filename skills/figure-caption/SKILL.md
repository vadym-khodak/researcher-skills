# Write Figure & Table Captions

## Overview

Writes accurate, self-contained captions for figures and tables following the conventions of the target journal, thesis format, or citation style. A good caption lets the reader understand the visual without reading the main text.

## Workflow

1. **Identify element type** — figure (chart, graph, map, image) or table
2. **Identify style requirements** — APA, ДСТУ, journal-specific, or institutional
3. **Gather information** — what the visual shows, any abbreviations used, data source
4. **Write caption** — following structure below
5. **Return** — formatted caption ready to place in the document

## Caption Structure

### Figure caption
```
Figure N. [Title sentence that describes what is shown.]
[Optional: additional detail — units, conditions, sample size, abbreviations.]
[Source: Author (Year) / Adapted from Author (Year) / Own elaboration.]
```

### Table caption
```
Table N. [Title sentence describing the content.]
[Optional: notes on methodology, abbreviations, statistical thresholds.]
[Source: …]
```

## Style Rules by Format

| Format | Figure label | Table label | Caption position | Source required |
|--------|-------------|-------------|-----------------|-----------------|
| APA 7th | *Figure N* (italic) | *Table N* (italic) | Figure: below; Table: above | Yes, as a Note |
| ДСТУ / Ukrainian thesis | Рис. N.N | Таблиця N.N | Figure: below; Table: above | Yes |
| IEEE | Fig. N | Table N (caps) | Both below | Yes |
| MLA | Fig. N | Table N | Both below | Yes |
| Chicago | Figure N | Table N | Both below | Yes |

## What a Self-Contained Caption Must Include

- **What** is shown (type of data, variable names)
- **Who / what** was measured (sample, population, entity)
- **When / where** if relevant (year, region)
- **Units** for all axes and values
- **Abbreviations** defined if not in the caption legend
- **Source** of the data or image

## Ukrainian-Specific Notes

| Convention | Rule |
|------------|------|
| Нумерація | In Ukrainian theses, figures and tables are numbered per chapter: `Рис. 2.3` = Chapter 2, Figure 3 |
| Підпис рисунку | Caption goes **below** the figure: `Рис. 2.3 — Назва рисунку` (em dash, not colon) |
| Підпис таблиці | Caption goes **above** the table: `Таблиця 2.3 — Назва таблиці` |
| Джерело | Required on the line below the caption: `Джерело: складено автором` / `Джерело: [автор, рік, с. N]` / `Джерело: адаптовано з [джерело]` |
| Скорочення | Define all abbreviations in a note below the figure/table |

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| Caption that repeats the axis labels | Describe what the data shows, not just what the axes are called |
| No source line | Every figure and table needs a source, even if "own elaboration" |
| Inconsistent numbering | Figures and tables are numbered in separate sequences — Figure 1, 2, 3 and Table 1, 2, 3 |
| Caption that requires the text to be understood | Captions must be self-contained — define abbreviations, include units |
