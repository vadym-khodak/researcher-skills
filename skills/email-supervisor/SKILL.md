# Write an Academic Email

## Overview

Drafts concise, professional emails for academic contexts: requesting feedback, reporting progress, following up on a submission, or communicating with editors and reviewers.

## Workflow

1. **Identify the recipient and purpose** — supervisor, editor, reviewer, collaborator, or institution
2. **Identify the ask** — what specific action or response is needed?
3. **Draft** — using the structure and tone guidelines below
4. **Return** — ready-to-send email; flag anything the user must personalise

## Email Structure

```
Subject: [Clear, specific subject — never blank or vague]

Dear [Dr./Prof./Mr./Ms. Surname],   ← use title if known

[Opening: 1 sentence — context or reminder of relationship]

[Body: the purpose, clearly stated in 2–4 sentences]

[Ask: one specific, actionable request]

[Closing: thank them; state any deadline if relevant]

Best regards / Sincerely,
[Full name]
[Affiliation, degree programme]
[Email | ORCID if relevant]
```

## Email Types & Key Elements

| Type | Key elements |
|------|-------------|
| Requesting feedback | Attach the document; state exactly what feedback you need; give a reasonable deadline |
| Progress update | What was done since last contact; what is next; any blockers |
| Following up | Reference prior email with date; be polite but direct; one follow-up is appropriate after 2 weeks |
| Submission inquiry | Manuscript title; confirm it fits scope before submitting; keep to 3–4 sentences |
| Declining a review request | Brief, no explanation required: "Thank you for the invitation. I am unable to review at this time." |

## Tone by Recipient

| Recipient | Tone |
|-----------|------|
| Thesis supervisor (established relationship) | Warm, direct, informal opener acceptable |
| New supervisor / potential advisor | Formal, respectful, demonstrate knowledge of their work |
| Journal editor | Formal, concise — editors receive hundreds of emails |
| Reviewer | You typically don't contact reviewers directly — go through the editor |
| Conference organiser | Professional, brief |

## Ukrainian-Specific Notes

| Context | Guidance |
|---------|----------|
| Звернення | Ukrainian academic emails: `Шановний(-а) [ім'я по батькові або посада]` — use ім'я по батькові for supervisors if you know it |
| Формальність | Ukrainian academic culture is more formal than Anglo-American — avoid first-name-only in initial emails |
| Наукові керівники | When emailing your supervisor, include your full name and group/programme in the signature — they may supervise many students |
| Підпис | Standard Ukrainian academic signature: ПІБ, спеціальність, курс, група, назва ЗВО |

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| Vague subject line ("Question" / "Help") | Be specific: "Feedback request: Chapter 2 draft — [Your name]" |
| No clear ask | End every email with one specific, actionable request |
| Too long | If it needs more than 150 words, ask whether a meeting is better |
| Following up too soon | Wait at least 5–7 business days before a follow-up; 2 weeks for editors |
| Sending without re-reading | Check: is the attachment attached? Is the recipient correct? |
