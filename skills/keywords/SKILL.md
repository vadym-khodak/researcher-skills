# Generate Academic Keywords

## Overview

Produces a set of keywords optimized for academic database indexing and search discoverability, following the conventions of the target journal or discipline.

## Workflow

1. **Gather inputs** — ask for: paper title, abstract (or topic summary), target journal or database, and any required keyword format (controlled vocabulary vs. free terms)
2. **Extract core concepts** — identify main topic, methodology, population/context, and discipline
3. **Generate candidates** — produce 10–15 candidate keywords
4. **Refine** — filter to 5–8 final keywords based on specificity, searchability, and journal requirements
5. **Return** — final keyword list in the required format, plus 3–5 alternates

## Keyword Selection Criteria

| Criterion | Guidance |
|-----------|----------|
| Specificity | Prefer specific terms over broad ones (`digital marketing` > `marketing`) |
| Searchability | Use terms researchers actually search for in databases |
| Coverage | Cover: main topic, method, population, discipline, key variables |
| Non-redundancy | Don't repeat words already in the title (they're already indexed) |
| Controlled vocabulary | If journal uses MeSH, ERIC, or similar — match those terms |

## Keyword Types to Include

| Type | Example |
|------|---------|
| Core topic | `social media marketing`, `machine learning` |
| Methodology | `systematic review`, `qualitative study`, `meta-analysis` |
| Population / context | `university students`, `SMEs`, `Ukraine` |
| Key variable or outcome | `brand loyalty`, `academic performance`, `carbon emissions` |
| Discipline / sub-field | `consumer behavior`, `public health`, `computational linguistics` |

## Format by Venue

| Venue | Convention |
|-------|-----------|
| Most journals | 4–8 keywords; Title Case or lowercase; semicolon-separated |
| APA journals | Italic, indented, lowercase except proper nouns |
| IEEE | Index Terms; Title Case |
| Scopus / WoS indexing | Free terms accepted; controlled vocab increases discoverability |
| Ukrainian academic (ДСТУ) | Ключові слова: listed after abstract; comma-separated |

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| Repeating title words | Skip them — search engines already index the title |
| Too broad (`research`, `study`, `analysis`) | Always pair with a domain (`marketing research`, `content analysis`) |
| Too narrow (unique phrases no one searches) | Check that each term returns results in Google Scholar |
| Ignoring bilingual requirements | Ukrainian journals often require keywords in Ukrainian + English |
| Exceeding the journal's keyword limit | Count carefully — many journals cap at 5 or 6 |
