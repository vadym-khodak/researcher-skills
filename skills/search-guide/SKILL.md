# Academic Search Strategy Guide

## Overview

Teaches researchers how to construct effective academic searches — from keyword selection through database choice to result evaluation.

## Step-by-Step Search Strategy

### 1. Decompose the Research Question

Break the question into core concepts:

> "How does social media marketing affect brand loyalty among Gen Z consumers?"

| Concept | Synonyms / Related Terms |
|---------|--------------------------|
| social media marketing | SMM, digital marketing, Instagram, TikTok |
| brand loyalty | brand attachment, customer retention, repeat purchase |
| Gen Z | Generation Z, digital natives, youth consumers |

### 2. Build Boolean Queries

| Operator | Effect | Example |
|----------|--------|---------|
| `AND` | Narrows — both terms must appear | `"brand loyalty" AND "Gen Z"` |
| `OR` | Broadens — either term | `"Gen Z" OR "Generation Z"` |
| `NOT` | Excludes | `marketing NOT advertising` |
| `"quotes"` | Exact phrase | `"social media marketing"` |
| `*` | Wildcard (stem) | `market*` → marketing, markets, marketplace |
| `(parentheses)` | Group OR alternatives | `("Gen Z" OR "Generation Z") AND loyalty` |

**Starter template:**
```
("concept 1" OR synonym1) AND ("concept 2" OR synonym2) AND ("concept 3" OR synonym3)
```

### 3. Choose Databases by Discipline

| Discipline | Primary Databases |
|------------|-------------------|
| Business, marketing | Scopus, Web of Science, Business Source Complete (EBSCO) |
| Medicine, health | PubMed, Cochrane Library, MEDLINE |
| Computer science | IEEE Xplore, ACM Digital Library, Semantic Scholar |
| Social sciences | JSTOR, PsycINFO, Sociological Abstracts |
| Ukrainian academic | НБУ ім. Вернадського (nbuv.gov.ua), Наукова Україна |
| Open access any | Google Scholar, BASE, DOAJ, OpenAlex |

### 4. Filter Results

Apply filters in this order:
1. **Date** — last 5–10 years (or wider for foundational/historical work)
2. **Document type** — journal articles, then conference papers, then books
3. **Language** — match your paper's requirements
4. **Peer-reviewed** — check "scholarly/peer-reviewed" filter in database

### 5. Evaluate Source Quality

| Signal | Good Sign | Warning |
|--------|-----------|---------|
| Journal | Indexed in Scopus/WoS | Not indexed anywhere |
| Citations | 10+ citations (adjust for recency) | 0 citations, published last month |
| Author | Institutional affiliation | No affiliation listed |
| Publisher | Known academic press | Predatory publisher |

Check predatory journals: [Beall's List](https://beallslist.net) or Think. Check. Submit. (thinkchecksubmit.org)

### 6. Manage Results

- Export to a reference manager (Zotero, Mendeley, EndNote)
- Tag sources by theme
- Note which queries found the most relevant results — iterate

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| Starting with Google instead of databases | Google Scholar is fine to start, but verify in a proper database |
| Too-broad query returning thousands of results | Add another `AND concept` to narrow |
| Too-narrow query returning nothing | Remove one concept or add `OR` synonyms |
| Stopping at the first page | Relevant papers often appear on page 2–5; also check "Cited by" links |
| Searching only in English | For regional topics, search local-language databases too |
