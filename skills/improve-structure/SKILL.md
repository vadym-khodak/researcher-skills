# Improve Paper Structure

## Overview

Reviews the current structure of a paper or section and suggests a reorganization that strengthens argument flow, logical progression, and reader navigation.

## Workflow

1. **Receive current structure** — ask user to paste the outline, headings, or full text
2. **Identify paper type** — empirical research, literature review, theoretical paper, thesis, or essay
3. **Diagnose issues** — identify structural problems (see checklist below)
4. **Propose new structure** — present a revised outline with brief rationale for each change
5. **Return** — revised outline + explanation of what was moved and why

## Standard Structure by Paper Type

### Empirical Research Paper (IMRaD)
```
1. Introduction      — background, gap, aim, structure preview
2. Literature Review — (sometimes merged with intro)
3. Methodology       — design, sample, data collection, analysis
4. Results           — findings without interpretation
5. Discussion        — interpretation, comparison to literature, implications
6. Conclusion        — summary, contribution, limitations, future research
```

### Literature Review / Theoretical Paper
```
1. Introduction      — scope, research question, search strategy
2. Thematic sections — grouped by concept, not chronology
3. Synthesis         — patterns, contradictions, gaps in the literature
4. Conclusion        — what the literature tells us; what remains unknown
```

### Thesis Chapter
```
1. Chapter intro     — what this chapter covers and why
2. Core content      — argument or findings
3. Chapter summary   — what was established; link to next chapter
```

## Structural Diagnosis Checklist

| Problem | Symptom |
|---------|---------|
| Buried thesis | Main argument appears only in conclusion, not introduced early |
| Chronological instead of thematic | Literature review organized by year, not concept |
| Results mixed with discussion | Interpretation appears in results section |
| Disconnected sections | No transitions; sections feel like separate essays |
| Redundant content | Same point made in introduction and conclusion without development |
| Weak conclusion | Conclusion only summarizes without stating contribution or implications |

## Ukrainian-Specific Notes

### Standard Ukrainian Thesis Structure (МОН)

```
Титульна сторінка
Завдання на дипломну роботу
Реферат (українська + англійська)
Зміст
Перелік умовних позначень (якщо є)
Вступ
  — актуальність теми
  — мета і завдання дослідження
  — об'єкт і предмет дослідження
  — методи дослідження
  — практичне значення
Розділ 1. Теоретичні засади…
Розділ 2. Аналіз…
Розділ 3. Практичні рекомендації / розробка…
Висновки
Список використаних джерел
Додатки
```

| Convention | Rule |
|------------|------|
| Вступ | Must contain: актуальність, мета, завдання, об'єкт, предмет, методи, новизна, практичне значення |
| Розділи | Typically 3 chapters for a master's thesis; each must end with висновки до розділу |
| Висновки | Mirror the завдання from the вступ — each task should have a corresponding conclusion |
| Обсяг | Bachelor's: 50–70 pages; Master's: 80–100 pages (excluding appendices and references) |

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| Reordering without explanation | Always explain why each change improves the argument |
| Proposing structure that doesn't fit the discipline | Check discipline conventions before suggesting changes |
| Moving content without flagging it | Note what text currently lives where; don't assume the user knows |
| Ignoring word/page limits | A restructure that adds sections must stay within the target length |
