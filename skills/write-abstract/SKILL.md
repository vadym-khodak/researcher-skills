# Write an Abstract

## Overview

Drafts or improves a structured abstract that accurately represents a paper's purpose, methods, findings, and conclusions within a strict word limit.

## Workflow

1. **Gather inputs** — ask for: the paper text or summary, target word limit, abstract type (structured or unstructured), and submission venue if known
2. **Identify abstract type** — structured (labeled sections) or unstructured (flowing prose)
3. **Draft** — cover all required elements proportionally within the word limit
4. **Check** — verify no claims appear in the abstract that are absent from the paper
5. **Return** — abstract + word count

## Abstract Elements

| Element | Unstructured | Structured label | Approx. share |
|---------|-------------|-----------------|---------------|
| Background / context | First 1–2 sentences | **Background** | 15% |
| Research gap or problem | Embedded | **Problem** / **Objective** | 10% |
| Aim / research question | 1 sentence | **Aim** / **Purpose** | 10% |
| Methods | 2–3 sentences | **Methods** | 25% |
| Results | 2–3 sentences | **Results** / **Findings** | 25% |
| Conclusions / implications | Final 1–2 sentences | **Conclusions** | 15% |

## Word Limits by Venue

| Venue | Typical limit |
|-------|--------------|
| Journal article | 150–250 words |
| Conference paper | 150–300 words |
| Thesis / dissertation | 300–500 words |
| Extended abstract | 500–1000 words |

Ask the user for the specific limit if not provided — never exceed it.

## Writing Rules

- Past tense for methods and results (`was conducted`, `were found`)
- Present tense for conclusions and standing facts (`results suggest`, `this study contributes`)
- No citations in the abstract (most venues prohibit them)
- No undefined abbreviations — spell out on first use or avoid
- No figures, tables, or footnotes
- Be specific: include numbers, not vague terms (`increased significantly` → `increased by 34%`)

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| Omitting results | An abstract without findings is incomplete — always include key results |
| Vague methods description | State what type of study, sample size, and analysis method |
| Introducing new claims | Abstract must reflect only what is in the paper |
| Exceeding the word limit | Cut background first; protect results and conclusions |
| Copy-pasting introduction sentences | Write the abstract fresh — it has a different structure than the intro |
