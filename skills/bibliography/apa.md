# APA 7th Edition — Complete Reference

Source: American Psychological Association. (2020). *Publication Manual* (7th ed.).

## General Rules

- Author format: Last, F. M. (surname + initials, comma-separated)
- Up to 20 authors: list all; 21+ authors: first 19 … last author
- Year in parentheses immediately after author block: `(Year).`
- Hanging indent (0.5 in / 1.27 cm)
- Italicize: book/report titles, journal names, volume numbers
- Article/chapter titles: sentence case (capitalize first word + proper nouns only)
- Journal names: Title Case
- DOI formatted as hyperlink: `https://doi.org/xxxxx` — no trailing period

---

## Books

**One author:**
```
Last, F. M. (Year). *Title: Subtitle* (Xth ed.). Publisher.
```
Kotler, P. (2017). *Marketing management* (15th ed.). Pearson.

**Two authors:**
```
Last, F. M., & Last, F. M. (Year). *Title*. Publisher.
```
Kotler, P., & Keller, K. L. (2022). *Marketing management* (16th ed.). Pearson.

**3–20 authors:**
```
Last, F., Last, F., & Last, F. (Year). *Title*. Publisher.
```

**Edited book:**
```
Last, F. M. (Ed.). (Year). *Title*. Publisher.
```

**Book chapter in edited volume:**
```
Last, F. M. (Year). Title of chapter. In F. M. Last (Ed.), *Title of book* (pp. XX–XX). Publisher.
```
Petrov, O. (2021). Consumer behavior in digital markets. In J. Smith (Ed.), *Digital marketing strategies* (pp. 45–67). Academic Press.

**Non-English book (for use in English paper — transliterate + translate):**
```
Last, F. M. (Year). *Transliterated title* [English translation]. Publisher.
```
Ivanov, O. V. (2020). *Tsyfrovyi marketynh* [Digital marketing]. Kyiv: Vydavnytstvo «Znannia».

## Journal Articles

**With DOI (preferred):**
```
Last, F. M., & Last, F. M. (Year). Title of article. *Journal Name*, *volume*(issue), pages. https://doi.org/xxxxx
```
Smith, J., & Jones, M. (2021). Social media marketing effectiveness. *Journal of Marketing*, *85*(3), 45–62. https://doi.org/10.1509/jm.20.0001

**Without DOI, with URL:**
```
Last, F. M. (Year). Title. *Journal Name*, *volume*(issue), pages. https://...
```

**Advance online publication (no volume/issue yet):**
```
Last, F. M. (Year). Title. *Journal Name*. Advance online publication. https://doi.org/xxxxx
```

## Dissertations & Theses

**From institutional repository:**
```
Last, F. M. (Year). *Title* [Doctoral dissertation, University Name]. Repository Name. URL
```
Ivanova, M. S. (2022). *Digital marketing strategies in Ukrainian SMEs* [Doctoral dissertation, Kyiv National Economic University]. KNEU Repository. https://...

**From ProQuest Dissertations:**
```
Last, F. M. (Year). *Title* [Doctoral dissertation, University]. ProQuest Dissertations & Theses. https://...
```

---

## Conference Papers

**Published in proceedings:**
```
Last, F. M. (Year). Title of paper. In F. M. Last (Ed.), *Proceedings title* (pp. XX–XX). Publisher. https://doi.org/xxxxx
```

**Presentation (unpublished):**
```
Last, F. M. (Year, Month). *Title* [Paper presentation]. Conference Name, City, Country.
```

## Reports

**Organization/government report:**
```
Organization Name. (Year). *Title of report* (Report No. XXX). Publisher. URL
```
World Economic Forum. (2023). *Global digital marketing trends*. https://...

## Websites

**With individual author:**
```
Last, F. M. (Year, Month Day). Title of page. *Site Name*. URL
```
Smith, J. (2023, March 15). How social media changed marketing. *HubSpot Blog*. https://...

**Organization as author:**
```
Organization. (Year, Month Day). Title of page. URL
```
Statista. (2024). Digital advertising spending worldwide 2019–2027. https://...

**No author, no date:**
```
Title of page. (n.d.). *Site Name*. URL
```

## In-Text Citation Quick Reference

| Case | Format |
|------|--------|
| 1 author | (Smith, 2021) |
| 2 authors | (Smith & Jones, 2021) — always both names |
| 3+ authors | (Smith et al., 2021) — always et al. |
| Direct quote | (Smith, 2021, p. 45) |
| Narrative | Smith (2021) found… |
| Secondary source | (Brown, 2015, as cited in Smith, 2021) — cite only Smith in reference list |

## Formatting Details

| Element | Rule |
|---------|------|
| Author initials | F. M. (space between initials) |
| Article title | Sentence case |
| Journal name | Title Case, *italics* |
| Volume | *Italics* |
| Issue | No italics, in parentheses — *(3)* |
| Pages (book) | `pp. XX–XX` |
| Pages (article) | `XX–XX` (no "pp.") |
| DOI | `https://doi.org/xxxxx` — no period at end |
| Edition | `(2nd ed.)` in parentheses after title |
| Translator | `(F. M. Last, Trans.)` after title |
| No date | `(n.d.)` |

## Ukrainian/Non-Latin Sources in English Papers

1. Transliterate author: Іванов О. В. → Ivanov, O. V. (use KMU 2010 table for Ukrainian)
2. Transliterate title
3. Add [English translation] in brackets immediately after transliterated title
4. Publisher city transliterated: Київ → Kyiv

Example:
Ivanov, O. V., & Petrenko, M. S. (2021). *Tsyfrovyi marketynh: teoriya ta praktyka* [Digital marketing: Theory and practice]. Kyiv: Vydavnytstvo «Znannia».
