# ДСТУ 8302:2015 — Повний довідник

Стандарт: ДСТУ 8302:2015 «Бібліографічне посилання. Загальні положення та правила складання»

## Загальні правила

- Автор: Прізвище І. Б. (спочатку прізвище, потім ініціали)
- 1–3 автори: перелічити всіх через кому
- 4+ автори: перший автор + **та ін.**
- Крапка після кожного блоку опису
- Тире ( — ) між відомостями про місце видання та видавця
- Скіс ( / ) перед відомостями про відповідальність після назви

---

## Книга (монографія, підручник, посібник)

**1 автор:**
```
Прізвище І. Б. Назва : вид. відомості. Місто : Видавець, Рік. XXX с.
```
Котлер Ф. Основи маркетингу : пер. з англ. Київ : Вільямс, 2019. 656 с.

**2–3 автори:**
```
Прізвище І. Б., Прізвище І. Б. Назва. Місто : Видавець, Рік. XXX с.
```
Іванов О. В., Петренко М. С. Цифровий маркетинг. Харків : Фоліо, 2021. 256 с.

**4+ автори (під іменем першого):**
```
Прізвище І. Б. та ін. Назва. Місто : Видавець, Рік. XXX с.
```
Іванов О. В. та ін. Маркетингові дослідження. Київ : КНЕУ, 2019. 400 с.

**Колективна праця під редактором:**
```
Назва / за ред. І. Б. Прізвища. Місто : Видавець, Рік. XXX с.
```
Стратегічний маркетинг / за ред. О. В. Іванова. Київ : Знання, 2022. 350 с.

## Іноземні джерела

Іноземні джерела включаються в загальний список мовою оригіналу. Прізвище — у тому порядку, що прийнятий у мові джерела (для англійських авторів: Last F. M. або Last, F.).

Kotler P., Keller K. L. Marketing Management. 16th ed. Hoboken : Pearson, 2022. 768 p.

## Сортування

1. Кирилиця (А–Я)
2. Латиниця (A–Z)
3. Нормативні акти — деякі ЗВО виносять окремим блоком **перед** основним списком
4. Архівні матеріали — окремо в кінці
