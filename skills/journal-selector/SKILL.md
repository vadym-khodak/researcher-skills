# Select a Target Journal

## Overview

Helps identify and compare journals that match a manuscript's topic, quality level, and author constraints (open access, speed, cost). Uses web search to retrieve current data.

## Workflow

1. **Gather manuscript profile** — topic, discipline, methodology, key findings, word count, author constraints (OA required? APC budget? Timeline?)
2. **Search for candidate journals** — use databases below
3. **Filter by fit** — scope match, audience, recent similar papers
4. **Compare shortlist** — impact factor, indexing, APC, turnaround time
5. **Return** — ranked shortlist of 3–5 journals with rationale

## Journal Evaluation Criteria

| Criterion | What to check |
|-----------|--------------|
| Scope match | Does the journal explicitly cover your topic? Read 5 recent articles |
| Indexing | Scopus, Web of Science, PubMed — affects visibility and institutional recognition |
| Impact Factor / CiteScore | Higher = more prestige; check current year (IF changes annually) |
| Quartile (Q1–Q4) | Q1 = top 25% in category; Q2–Q4 progressively lower |
| Open access | Fully OA (DOAJ), hybrid, or subscription — affects APC cost |
| APC (Article Processing Charge) | $0–$5000+; check if your institution has a waiver agreement |
| Turnaround time | First decision: days to months; check journal's stated timeline |
| Acceptance rate | Lower = more selective; many journals don't publish this |

## Predatory Journal Warning Signs

- Not indexed in Scopus, WoS, or DOAJ
- Unrealistically fast peer review (< 1 week)
- Requests payment before peer review
- Scope is implausibly broad ("all science and technology")
- Check Beall's List (beallslist.net)

## Ukrainian-Specific Notes

| Topic | Guidance |
|-------|----------|
| ВАКівські журнали | For Ukrainian degree requirements, the journal must be in МОН's approved list (наукові фахові видання) — check mon.gov.ua |
| Категорії А, Б, В | Ukrainian journals are ranked A (highest), B, C by МОН; category A journals carry the most weight for degree defense |
| Scopus/WoS requirement | PhD candidates at many Ukrainian universities must publish at least one article in a Scopus or WoS indexed journal |
| Безкоштовні OA варіанти | DOAJ lists many legitimate free-to-publish open-access journals; useful when there is no APC budget |

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| Choosing by impact factor alone | A Q1 journal outside your field is a worse fit than a Q2 journal in your field |
| Not reading recent issues | Scope descriptions are sometimes vague — read 5 recent papers to verify fit |
| Ignoring turnaround time | If you have a thesis deadline, a 12-month review cycle is a problem |
| Submitting to a predatory journal | Always verify indexing before submitting |
