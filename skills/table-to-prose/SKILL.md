# Convert Table to Prose

## Overview

Translates tabular data into clear, accurate written paragraphs suitable for a results or discussion section. Highlights key patterns, comparisons, and notable values — does not describe every cell.

## Workflow

1. **Receive the table** — ask user to paste the table and state what it shows
2. **Identify the narrative** — what is the most important pattern, trend, or comparison?
3. **Select what to highlight** — pick 3–5 key values; the rest stay in the table
4. **Write prose** — lead with the main finding, support with specific values, end with interpretation if in discussion
5. **Return** — prose paragraph + confirm the table remains in the paper (prose supplements, not replaces it)

## What to Highlight vs. What to Leave in the Table

| Highlight in prose | Leave in table |
|-------------------|----------------|
| Highest and lowest values | All intermediate values |
| Unexpected or noteworthy results | Expected/unremarkable data points |
| Key comparisons between groups | Full breakdown of all groups |
| Results that directly answer the research question | Supporting context data |
| Values that will be discussed or explained | Raw counts when percentages are cited |

## Prose Patterns

**Describing a trend:**
> "Table 2 shows that brand awareness increased consistently across all age groups, with the largest gain among 18–24-year-olds (from 34% to 61%) and the smallest among those over 55 (from 51% to 54%)."

**Comparing groups:**
> "As shown in Table 3, respondents in urban areas reported significantly higher social media usage (M = 4.2 h/day, SD = 1.1) compared to rural respondents (M = 2.8 h/day, SD = 0.9)."

**Highlighting an exception:**
> "While most indicators improved following the intervention (Table 4), customer retention declined by 3 percentage points — the only metric to show a negative trend."

## Results vs. Discussion Prose

| Section | Prose focus |
|---------|-------------|
| Results | Report what the data shows — no interpretation. Use: "Table N shows…", "As indicated in Table N…" |
| Discussion | Interpret what the pattern means. Use: "The decline in retention (Table 4) may reflect…" |

## Ukrainian-Specific Notes

| Convention | Rule |
|------------|------|
| Посилання на таблицю | In Ukrainian academic text: `(табл. 2.3)` or `(див. табл. 2.3)` — abbreviated, in parentheses |
| Підпис | Table caption goes ABOVE the table in Ukrainian theses: `Таблиця 2.3 — Назва таблиці` |
| Числа | Use comma as decimal separator in Ukrainian text: `4,2 год/день` |
| Одиниці вимірювання | Always state units in the prose when citing a value |

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| Describing every cell | Select key values only — the table already shows everything |
| Not referencing the table | Always include `(Table N)` or `as shown in Table N` |
| Replacing the table with prose | Prose supplements the table; both stay in the paper |
| Interpreting results in the Results section | Save interpretation for the Discussion |
