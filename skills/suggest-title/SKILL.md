# Suggest a Title

## Overview

Generates multiple title options for an academic work, covering different stylistic approaches, then helps the user choose and refine the best one.

## Workflow

1. **Gather inputs** — ask for: topic/research question, key findings, target journal or venue, discipline, and any title style preferences
2. **Generate options** — produce 4–6 titles across different structural patterns
3. **Annotate** — briefly explain the strategic strength of each option
4. **Refine** — iterate on the user's preferred option if needed

## Title Patterns

| Pattern | Structure | Example |
|---------|-----------|---------|
| Descriptive | States what the study is about | "Social Media Use and Academic Performance Among University Students" |
| Question | Poses the research question | "Does Social Media Harm Student Performance?" |
| Colon (main + subtitle) | Catchy phrase: descriptive subtitle | "Scrolling to Fail: Social Media Use and GPA Decline in Higher Education" |
| Finding-forward | States the main result | "Social Media Use Reduces GPA by Up to 0.4 Points: A Longitudinal Study" |
| Method-forward | Highlights methodology | "A Systematic Review of Social Media's Impact on Academic Outcomes" |

## Title Quality Criteria

| Criterion | Check |
|-----------|-------|
| Specificity | Does it tell the reader exactly what the study is about? |
| Keywords | Does it contain the main searchable terms for discoverability? |
| Length | Journal articles: 10–15 words optimal; thesis: up to 20 words |
| Accuracy | Does it match what the paper actually delivers? |
| No hype | Avoids "novel", "first-ever", "groundbreaking" unless literally true |
| No abbreviations | Spell out acronyms in the title (except universally known ones) |

## Discipline Conventions

| Discipline | Tendency |
|------------|----------|
| Sciences (medicine, biology) | Descriptive, finding-forward, colon structure common |
| Social sciences | Colon structure very common; question titles also used |
| Humanities | Allusive or metaphorical main title + descriptive subtitle |
| Engineering / CS | Descriptive, method-forward; questions rare |
| Ukrainian academic | Descriptive; colon structure standard in theses |

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| Too vague ("A Study of Marketing") | Add population, method, or finding to narrow |
| Too long (25+ words) | Cut adjectives and filler phrases |
| Missing key search terms | Include the main concept words researchers would search for |
| Overclaiming in the title | Match title claims to what the paper actually proves |
