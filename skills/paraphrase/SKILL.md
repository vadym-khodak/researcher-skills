# Paraphrase

## Overview

Rewrites a passage in different words while preserving the original meaning. Does not add, remove, or distort information.

## Workflow

1. **Clarify purpose** — ask if unclear: avoiding plagiarism, changing register, simplifying, or adapting for a new audience
2. **Clarify register** — match the target document's style (academic formal, plain language, etc.)
3. **Paraphrase** — restructure sentences, replace vocabulary with synonyms, vary sentence length
4. **Verify** — confirm the core meaning is intact and no detail was dropped or added
5. **Return** — paraphrased version, with a note if any phrase was kept close to the original due to technical necessity

## Paraphrasing Techniques

| Technique | Example |
|-----------|---------|
| Synonym substitution | "utilize" → "use"; "demonstrate" → "show" |
| Sentence restructuring | Active ↔ passive; split long sentences |
| Perspective shift | "Researchers found…" → "The study revealed…" |
| Abstraction change | Specific example → general principle (or reverse) |
| Voice and tense | Change narrative voice while keeping meaning |

## What NOT to Change

- Factual content, numbers, statistics
- Proper nouns (names, places, titles)
- Technical terms with no accepted synonym
- The logical structure of an argument

## Degree of Paraphrase

| Goal | Approach |
|------|----------|
| Avoid plagiarism | High degree — restructure and re-vocabulary substantially |
| Change tone/register | Moderate — adjust vocabulary and formality |
| Clarify meaning | Light — untangle complex phrasing, keep close to original |

Always cite the original source after paraphrasing — paraphrase does not eliminate the citation requirement.

## Ukrainian-Specific Notes

| Issue | Guidance |
|-------|----------|
| Паразитизм суржику | When paraphrasing Ukrainian text, check the result for Russian-origin words introduced accidentally — restructuring often surfaces calques |
| Гнучкий порядок слів | Ukrainian allows freer word order than English — use this to restructure sentences genuinely: move the rheme (new info) to the end |
| Паразитні кальки з англійської | When paraphrasing English sources into Ukrainian, avoid literal translation: `take into account` → `враховувати` (not `приймати до уваги`) |
| Синоніми | Ukrainian has distinct synonym sets from Russian — use a Ukrainian dictionary (e.g., slovnyk.ua) to verify synonyms are genuinely Ukrainian |
| Цитування | ДСТУ requires a citation even after paraphrase — use `[N]` format matching your reference list |

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| Changing only a few words (near-copy) | Restructure sentences entirely, not just swap synonyms |
| Altering the meaning | Re-read the original after paraphrasing; verify facts match |
| Removing nuance or hedging language | Keep epistemic markers (`may`, `suggests`) if they were in the original |
| Paraphrasing direct quotes | Direct quotes should remain quoted — only paraphrase indirect content |
